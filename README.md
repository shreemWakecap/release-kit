# Presentation bank (Connected Environment release kit)

Everything we made for the Connected Environment 1.0 release story, in one place.

| Folder | What is in it |
|---|---|
| `presentation/` | The interactive HTML decks (7-slide demo, all-slides deck), their source, the ideas bank, research notes, and the first PowerPoint deck. Start with `presentation/README-FIRST.md` if present, or open `presentation/connected-environment-story.html`. |
| `four-videos/` | The four product videos, the setup tour, narration, captions and the tools that made them. |
| `walkthrough/`, `demo/`, `sellit/` | Earlier walkthrough, demo and sales-page material. |
| `internal-notes.md`, `release-note.md` | Release notes (internal notes are for internal reading). |

Open any `.html` deck by downloading the file and double-clicking it. Press F for full screen and the right arrow to play a slide.
